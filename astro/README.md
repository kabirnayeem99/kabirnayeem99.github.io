# Astro Workspace

Astro is the only site pipeline in this repository.

## Commands

```bash
npm ci
npm run dev
npm run verify # every check; --help lists the faster groups
```

## Notes

- Scripts in `scripts/` run directly (`scripts/css.ts --help`). They take `-h`/`--help` and
  long `--kebab-case` flags, write diagnostics to stderr, and exit with 0 (done), 1 (failed),
  2 (usage error) or 130 (interrupted). Extra `npm run dev` arguments go to `astro dev`.
- Styles live in `src/styles/` (one file per component; `index.css` sets the import order).
  `npm run css:build` bundles them into `public/assets/css/styles.css`, which is generated and
  not tracked; `dev`, `build` and `check` run it, and `dev` keeps watching.
- Everything is TypeScript. The inline `<head>` scripts (`src/inline/`) and the service worker
  (`src/sw/`) are compiled to text by `scripts/compile-script.ts`.
- Content files live in `src/data/site-content/` (split by shared sections and per-page JSON).
- `robots.txt` and `sitemap.xml` are generated by Astro routes.
- Deployment uploads `dist/` to GitHub Pages.
